A tiny program for the make.fun competition "One Word, One Username, One Reward".

It writes exactly one word — the entrant's own make.fun username — to
`/output/entry.txt`, with no trailing newline, no padding, and nothing else.

Run it with Node 22:

```sh
node main.ts
```

The output directory honours `MAKEFUN_OUTPUT_DIR` and falls back to `/output`.
